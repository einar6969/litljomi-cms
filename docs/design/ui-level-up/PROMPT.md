# Opening prompt for the KING session

Put the `ui-level-up` folder at `docs/design/ui-level-up/` in your local checkout first. Then paste this into the KING session:

```text
Next job: a frontend level-up of the Hub, starting with simplifying how we work on frontend.

Read docs/design/ui-level-up/BRIEF.md and look at the screenshots in docs/design/ui-level-up/references/. Then read only what you need from the repo; the brief points to the relevant files.

This job has four phases, each ending with a stop for me. Start with Phase 0 only:
1. Tell me briefly which parts of our current workflow you'd drop or shorten for frontend-only work, and why.
2. Draft the UI fast lane as the brief describes (one page at most), plus the allowlist check and any CLAUDE.md or .claude changes as exact diffs.
3. Stop and wait for my approval. Don't change, commit or push anything yet.

After I approve Phase 0, Phase 1 is your own mockups in a Design artifact. Mine in references/ are inspiration only. If you don't have the Design artifact tool, tell me.
```
