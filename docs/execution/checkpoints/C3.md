## How you can see it yourself

Run each block in your own terminal (outside the sandbox). Ports 3100 (CMS), 3200 (LABAK); the stack must be running (`pnpm db:start`, OrbStack on).

**1. Local stack, test identities and LABAK's local site record**

```bash
cd /Users/einarzoega/litljomi-cms && pnpm db:reset && pnpm seed:local && pnpm seed:labak-site
```

**2. The CMS (leave running)**

```bash
cd /Users/einarzoega/litljomi-cms && export CMS_INTERNAL_SECRET=local-internal CRON_SECRET=local-cron CMS_PUBLIC_URL=http://localhost:3100 && sh tests/integration/scripts/cms-next.sh build && sh tests/integration/scripts/cms-next.sh start -p 3100 -H 127.0.0.1
```

**3. Sign in from another browser.** In browser A (e.g. Safari) open http://localhost:3100/login and request a link for `editor-labak@test.local`. Open Mailpit at http://127.0.0.1:54324, copy the "Skrá inn" link, and paste it into browser B (e.g. Chrome, or a private window). Press "Halda áfram": B lands on `/t/labak`, signed in; A is still signed out. Opening the link without pressing the button signs nobody in.

**4. Publish a first article.** In B: Fréttir → "Ný færsla", fill Titill, Dagsetning, Inngangur, choose an image (any JPEG), type a body, "Vista slóð", then "Birta". It stays at "Í birtingu…" because the LABAK site is not running yet.

**5. LABAK's site on the branch, reading the local CMS (leave running)**

```bash
cd "/Users/einarzoega/Documents/Litljómi ehf/Projects/2026/LAW Takeover/LABAK/landssamband-bakarameistara" && git switch hub-integration && rm -rf .next && export CMS_DELIVERY_BASE_URL=http://127.0.0.1:54321/storage/v1/object/public/delivery CMS_TENANT=labak CMS_WEBHOOK_SECRETS=labak-local-secret CMS_MEDIA_HOST=127.0.0.1 CMS_MEDIA_PROTOCOL=http CMS_MEDIA_PORT=54321 CMS_MEDIA_ALLOW_LOCAL_IP=1 NEXT_TELEMETRY_DISABLED=1 && npx next build && npx next start -p 3200 -H 127.0.0.1
```
